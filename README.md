# Phishing Detection Test

A collection of static web pages created to test our phishing detection system.

These pages simulate common phishing characteristics such as:

- Fake login forms
- Suspicious authentication flows
- Urgency/social-engineering language
- Brand-like interfaces
- Suspicious navigation and URLs

## Purpose

This repository is used exclusively for development, testing, and evaluation of our phishing detection system.

The sites are static test fixtures and do not implement real authentication or credential collection.




## Disclaimer

All services and brands represented in this repository are fictional and are used solely for security testing. This project is not affiliated with any real company or service.
